使用说明

中文盲文翻译网页端：输入流程、OCR 注意事项、表格还原、许可与 API。

主流程

  1. 在「盲文输入」粘贴 Unicode 盲文；表格可用 | 分隔单元格、|| 分隔行，粘贴后会自动成可编辑表格。
  2. （可选）填写上下文，选择后端（默认 qwen8b）。
  3. 整表或含分隔符内容请勾选「按表格还原」（含 | 时会自动勾选）。
  4. 点「翻译」；结果区显示汉字；若有表格可点击单元格定位，并用朗读按钮听读。
  5. （可选）上传图片后点「识别并翻译」，走 OCR → 翻译流水线。

图片 OCR 说明

支持两类图：

  • 网页 / Unicode 盲文表格截图：自动切格并读取 U+2800 段盲文字形。
  • 凸起点阵照片：需要较清晰的实心圆点。
空心圈教材图、严重模糊或反光过强的照片容易失败。此时请改从主页面直接粘贴 Unicode 盲文。

图片识别接口为 POST /v1/pipeline（OCR → 单元格翻译 → 表格还原）。

表格与样例

  • 检测到 | / || 时会展开「输入表格」，可直接改单元格，文本区会同步。
  • 样例芯片可一键填入短语或整表（含 data-sample / data-cells 精确网格）。
  • 结果表格支持点击 / 方向键选格、行列定位、朗读单元格 / 本行 / 整表。
  • Markdown / CSV 在结果区折叠面板中导出。

许可

本工具演示用途。默认所用基座模型许可多为 CC BY-NC-SA，仅限非商业使用。请同时遵守仓库 LICENSE 与上游模型条款。

API 一览

  • GET /health — 服务与适配器状态
  • POST /v1/translate — 盲文 → 汉字（可 as_table）
  • POST /v1/detect — 图片检测 / OCR
  • POST /v1/pipeline — 识别并翻译
  • 交互式文档：/docs（OpenAPI）

仓库内 Markdown 说明见 docs/web-ui.md。

纠错与再训

还原表格若有错字：选中单元格 → 改正汉字 →「保存纠错」。攒够样本后点「准备再训」，在本机 Windows CUDA 运行提示的 PowerShell 命令短训 LoRA，再替换 models/lora_tables 并重启服务。

详见仓库 docs/continuous_improve.md。
